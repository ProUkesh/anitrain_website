# AniTrain Liquid Hero v3

This ZIP is meant to be extracted directly into your existing Next.js AniTrain project.

It replaces:

- `app/page.tsx`
- `app/globals.css`

## Install from Terminal

Stop the dev server first with `Ctrl + C`, then run:

```bash
cd ~/projects/Anitrain-website
unzip -o ~/Downloads/anitrain-liquid-hero-v3.zip
npm run dev
```

Then open:

```text
http://localhost:3000
```

## What changed

- Pure black `#000000` theme
- Removed the `TRAIN BEYOND REALITY • 2026` line
- Cleaner, more spaced `AniTrain` hero word
- Apple-inspired liquid lens hover over the `AniTrain` text
- No neon glow
- Added the quote: `Train like the hero of your own arc.`
- Character bubbles continue floating with subtle mouse depth/parallax
- Some bubbles sit behind the word and some sit in front

## Character images

The current images are temporary remote fitness images so the animation works immediately.
Later, replace them with your own AniTrain character assets for production.
