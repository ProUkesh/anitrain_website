# AniTrain Hero — Black v2

Pure-black hero prototype with:
- pure #000 background
- no glow/aura effects
- liquid AniTrain hover distortion
- floating character bubbles
- cursor parallax
- remote image-search character references for prototype use

## Run

```bash
npm install
npm run dev
```

## Important
The remote character images are temporary prototype references discovered through web image search. Before production, replace them with artwork you own or have licensed for AniTrain.
